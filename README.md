# Multi-Agent Computer Platform System Engineering Services Section

This section specializes agent computer platform system engineering to
platforms that host, compose, and coordinate multiple agents.

Its apps may compose reusable agent-computer-system apps and platform apps
owned by upstream sections. Further environmental or protocol specializations
continue under `services/`.

## Apps

- `apps/spotcomp` — SPOTCOMP, a computer operating over
  Subject–Predicate–Object Traces and running Modeled Players.
